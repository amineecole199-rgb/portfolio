# Portfolio — Amine ELHAMRI

> **Développeur Full-Stack • Élève ingénieur ENSA en Génie Informatique & Industriel**

Un portfolio moderne, architectural et aéré conçu selon une esthétique **Light Duotone** à **bordures strictes 90°**, bilingue (**FR / EN**), avec des démonstrations vidéo et des prototypes interactifs dont le contexte est indiqué sur chaque projet.

---

## 🚀 Projets Présentés

1. **MzadAuto.app** — Plateforme SaaS d'enchères automobiles en direct (WebSockets <50ms, Laravel 12, Vue 3, Inertia.js, Redis, MySQL). Le site public et une démonstration vidéo sont accessibles depuis le portfolio.
2. **DRA-RSK : Générateur d'Indemnités & Audit Budgétaire (Stage)** — Application web de dématérialisation comptable et d'audit algorithmique (Laravel, PHP 8.3, Pest, Verrouillage pessimiste SQL). *Note : Exemples de simulation générés avec l'IA pour préserver la confidentialité des données publiques.*
3. **Majest Drive & Pipeline B2B** — Écosystème d'acquisition client, scraper B2B et passerelle WhatsApp.
4. **Boutique PrestaShop & Passerelle 3andiBricole** — E-Commerce sur-mesure et bot WhatsApp (Baileys / Node.js).

---

## 🛠️ Stack & Technologies

- **Architecture** : HTML5 sémantique, Vanilla CSS (Design System 90° Duotone), JavaScript ES6+ (Moteur bilingue FR/EN dynamique).
- **Typographie** : `Space Grotesk`, `Plus Jakarta Sans`, `JetBrains Mono`.
- **Documents** : CV interactif A4 imprimable en version française (`cv.html`) et anglaise (`cv_en.html`).
